# RA | Excel Dashboard Projects

Recruiter-facing spreadsheet portfolio projects using **synthetic data only**. Each workbook is designed to demonstrate practical Operations, PMO, reporting, customer-service analytics, inventory control and logistics skills.

## 1. Operations & PMO Executive Dashboard

**File:** [RA_Operations_PMO_Executive_Dashboard.xlsx](RA_Operations_PMO_Executive_Dashboard.xlsx)

Demonstrates:
- Executive KPI reporting
- Project RAG status
- Overdue and blocked-task tracking
- RAID management
- Project completion monitoring
- Data validation, conditional formatting and management charts

## 2. Customer Service SLA Dashboard

**File:** [RA_Customer_Service_SLA_Dashboard.xlsx](RA_Customer_Service_SLA_Dashboard.xlsx)

Demonstrates:
- SLA compliance and breach tracking
- Open-backlog visibility
- CSAT reporting
- Channel and priority analysis
- Agent-level performance summaries

## 3. Inventory & Logistics Control Dashboard

**File:** [RA_Inventory_Logistics_Control_Dashboard.xlsx](RA_Inventory_Logistics_Control_Dashboard.xlsx)

Demonstrates:
- Inventory valuation
- Stock-cover analysis
- Reorder-point logic
- Critical-stock risk flags
- Supplier and lead-time reporting
- Logistics management visibility

## Public-data note

All workbook records are synthetic and created for portfolio demonstration. No employer, customer, candidate or private operational data is included.
