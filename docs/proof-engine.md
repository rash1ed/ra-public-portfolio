# Proof Engine

The portfolio is designed as a reusable proof system, not a static showcase.

Each verified project is translated into professional outputs only after its evidence is inspectable.

## Publication workflow

1. Build the smallest useful version.
2. Test it against reproducible cases.
3. Capture the actual output and limitations.
4. Sanitize credentials, identities and private data.
5. Verify every numeric claim against public or reproducible evidence.
6. Publish the project before promoting new skills or claims.
